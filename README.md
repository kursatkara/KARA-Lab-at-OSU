# KARA Lab at OSU

Website of the Kara Aerodynamics Research Laboratory (Kursat Kara, Oklahoma State University), live at https://www.kursatkara.com.

Everything is in one file, `index.html`: plain HTML with inline CSS and a little JavaScript. There is no build step.
Edit it in any text editor, on GitHub's web editor, or ask Claude/Codex; see `AGENTS.md` for the conventions.

Preview locally:

    python3 -m http.server 8000   # then open http://localhost:8000
